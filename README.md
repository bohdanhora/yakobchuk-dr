# yakobchuk-dr

Открытка с днём рождения для Елизаветы.

## Запуск

```bash
npm install
npm run dev
```

До 24 ноября показывается обратный отсчёт. Чтобы открыть открытку раньше, добавьте `?preview` к адресу: `http://localhost:5173/?preview`.

## Где что менять

- Все тексты, подписи и дата: `src/content.ts`
- Фото: положить в `public/photos/` и указать путь в `content.photos.items`, например `src: '/photos/1.jpg'`
- Музыка: положить файл в `public/music/song.mp3`. Если файла нет, кнопка музыки просто не появится
- Цвета и шрифты: `src/index.css`, блок `@theme`
- Подпись рукописным шрифтом рисуется компонентом `Signature` для любой строки из `content.ts`, отдельно ничего готовить не нужно

## Микрофон

Свечи можно задуть по-настоящему: доступ к микрофону запрашивается только после нажатия кнопки «Задуть по-настоящему». Браузеры дают микрофон только по HTTPS (или на localhost), поэтому на телефоне это заработает после деплоя. Чувствительность настраивается константами в `src/hooks/useBlow.ts`.

## Головоломка

Перед поздравлением нужно заполнить поле 6x6 восемью фигурами (без поворотов). Раскладка задаётся строками в `src/lib/puzzle.ts`: одна буква на клетку, одинаковые буквы образуют фигуру. Кнопка подсказки появляется после трёх неправильных ходов.

## Музыка

Первый трек пытается включиться сразу при открытии. Телефоны не дают сайту играть звук до первого касания, поэтому на телефоне музыка начнётся от первого касания в любом месте экрана. Второй трек плавно сменяет первый, когда начинается прокрутка поздравления.

## Особые гости

Сцена-поздравление в формате визуальной новеллы, блок `story` в `src/content.ts`:

- `characters`: у каждого героя `name`, `tagline` (характеристика), `portrait`, `accent` (цвет свечения и таблички имени) и `lines` (реплики)
- портреты кладите в `public/characters/` и указывайте путь, например `portrait: '/characters/hero1.png'`. Лучше всего подходят PNG с прозрачным фоном в полный рост или по пояс. Пока портрета нет, рисуется силуэт с первой буквой имени
- у реплики могут быть `choices`: варианты ответа с `reply` (реакция героя). `special: true` делает вариант золотым
- выбрать можно только одного героя, выбор сохраняется в браузере и переживает перезагрузку. Чтобы сбросить его при тестировании, откройте адрес с `?reset-choice`, например `/?preview=card&reset-choice`

Для быстрой проверки откройте `/?preview=card`: открытка откроется сразу, без конверта и головоломки.
