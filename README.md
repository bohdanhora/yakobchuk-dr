# yakobchuk-dr

Открытка с днём рождения для Елизаветы.

## Запуск

```bash
npm install
npm run dev
```

До 24 ноября показывается обратный отсчёт. Чтобы открыть открытку раньше, добавьте `?preview` к адресу: `http://localhost:5173/?preview`.

## Где что менять

- Все тексты, подписи и дата: `src/content.ts`
- Фото: положить в `public/photos/` и указать путь в `content.photos.items`, например `src: '/photos/1.jpg'`
- Музыка: положить файл в `public/music/song.mp3`. Если файла нет, кнопка музыки просто не появится
- Цвета и шрифты: `src/index.css`, блок `@theme`
- Подпись рукописным шрифтом рисуется компонентом `Signature` для любой строки из `content.ts`, отдельно ничего готовить не нужно

## Микрофон

Свечи можно задуть по-настоящему: доступ к микрофону запрашивается только после нажатия кнопки «Задуть по-настоящему». Браузеры дают микрофон только по HTTPS (или на localhost), поэтому на телефоне это заработает после деплоя. Чувствительность настраивается константами в `src/hooks/useBlow.ts`.
